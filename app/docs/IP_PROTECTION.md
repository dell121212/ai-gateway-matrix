# 关于授权与「保护」管线（开源说明）

本项目已按**开源**方向调整：

| 能力 | 默认 |
|------|------|
| 启动授权闸 | **关闭**（`run.sh` 不拦截） |
| deb 源码混淆 / 水印 | **关闭**（明文打包） |
| `AGM_ENFORCE_LICENSE=1` | 可选，几乎用不到 |
| `AGM_PROTECT=1` | 可选保护构建，默认不需要 |

历史代码仍保留在：

- `app/licensing/` — 离线 license 实验  
- `app/packaging/protect/` — 去注释/水印实验  

开源贡献与自用请忽略上述目录即可。
